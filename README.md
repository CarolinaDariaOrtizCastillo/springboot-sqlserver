# Springboot + SQLserver

---

## 📖 Descripción del Proyecto
Este proyecto es una aplicación backend desarrollada con **Spring Boot** que gestiona información de clientes utilizando **SQL Server** como base de datos.  
Permite realizar operaciones CRUD sobre clientes y cuenta con documentación de endpoints vía **Swagger UI**.  
El proyecto sigue buenas prácticas con capas de **model, repository, service y rest** para una arquitectura limpia y escalable.

---

## 🌐 Endpoints del Proyecto
### API CLIENTES
http://localhost:8012/v1/api/customer

### Swagger (Documentación de API)
http://localhost:8012/swagger-ui/index.html
